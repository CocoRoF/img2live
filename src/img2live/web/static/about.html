소개

img2live가 하는 일, 작동 방식, 그리고 솔직한 한계.

한 장의 일러스트에서 움직이는 퍼펫까지

캐릭터 일러스트를 올리면 머리카락·얼굴·눈·몸·옷 등을 가려진 부분까지 복원해 레이어로 분해하고, 레이어마다 메시와 변형 키폼을 만들어 자동으로 리깅합니다. 결과는 브라우저에서 바로 움직여 볼 수 있고, 레이어를 켜고 끄고, 잘못 나뉜 곳을 고치고, 마음에 안 드는 레이어만 다시 생성할 수 있습니다.

작동 방식

1

안전 검사

GPU를 쓰기 전에 성적 콘텐츠·미성년 묘사·사진·다인 이미지를 걸러냅니다.

2

레이어 분해

머리카락(앞/뒤)·얼굴·눈·눈썹·코·입·귀·목·옷·팔·다리·신발 등을 RGBA 레이어로 나눕니다. (See-through 방법론 기반 자체 구현)

3

자동 리깅

머리 회전·눈·시선·눈썹·입·몸·머리카락의 변형 키폼과 물리를 만들고 수치 QA로 접힘을 검사합니다.

4

보고, 고치고, 다시 생성

스튜디오에서 움직여 보고, 레이어를 지우거나 옮기고, 레이어 하나만 다시 생성합니다.

솔직한 한계

  • 자동 리그의 수준은 "기본 모션"입니다(깜빡임·시선·머리 회전·호흡·머리카락 흔들림). 전문가가 손으로 만든 Live2D 모델 수준은 아닙니다.
  • 감은 눈·벌린 입 그림은 생성하지 않습니다. 눈 감김은 속눈썹이 닫힘 곡선으로 내려오는 방식, 입 열림은 템플릿 입 모양으로 처리하며 결과 보고서에 degraded 로 표시됩니다. 모음(아이우에오) 입 모양은 아직 없습니다.
  • 전신 이미지는 얼굴이 작아 해상도가 부족할 수 있습니다. 상반신·고해상도 입력이 더 좋은 결과를 줍니다.
  • 분해가 잘못될 수 있습니다(포니테일이 뒷머리에 합쳐짐, 안경·동물 귀 누락, 소스에 없는 윤곽이나 띠 등). 스튜디오의 레이어 패널에서 실제 분해를 보고 고칠 수 있습니다.
  • 이 서비스는 Live2D Inc.와 무관하며 Cubism SDK를 사용하지 않습니다. 자체 형식으로 내보냅니다.

보관과 개인정보

퍼펫은 만든 뒤 1년 보관되고, 삭제하면 서버에서 바로 지워집니다. 로그인이 없어서 "내 퍼펫" 목록은 이 브라우저에만 저장됩니다. 자세한 내용은 이용약관·고지를 보세요.

사용한 기술과 출처

레이어 분해는 See-through(Apache-2.0)에서 파생된 코드와 OpenRAIL++-M 가중치를 사용합니다. 소스는 GitHub에 공개되어 있고, 문제나 제안은 이슈로 남겨 주세요.
