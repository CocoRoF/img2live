일러스트 한 장으로,
움직이는 2D 퍼펫.

캐릭터 일러스트와 프롬프트를 올리면 레이어로 분해하고(가려진 부분까지 복원), 눈 깜빡임·시선·머리 회전·호흡·머리카락 흔들림을 자동으로 리깅해서 브라우저에서 바로 움직여 볼 수 있습니다. 모든 중간 결과(레이어, 비교, 리그 보고서, 파일)를 직접 확인하고 내려받을 수 있습니다.

1. 이미지와 프롬프트

이미지를 끌어다 놓거나 클릭
PNG · JPEG · WebP, 최대 12MB. 한 명의 캐릭터가 또렷한 애니풍 일러스트(정면 전신/상반신)가 가장 잘 됩니다.

프롬프트는 동작 설정(동작 크기·머리카락/꼬리 흔들림·깜빡임·대기 동작)으로 해석됩니다. 어떤 부위를 분리할지는 바꿀 수 없습니다. 해석 결과는 아래에 그대로 보여 드립니다.

처리 한도

    결과는 비공개 링크로만 열리며 72시간 뒤 자동 삭제됩니다. 언제든 직접 삭제할 수 있습니다.

    작동 방식

    1

    안전 검사

    GPU를 쓰기 전에 성적 콘텐츠·미성년 묘사·사진·다인 이미지를 걸러냅니다.

    2

    레이어 분해

    머리카락(앞/뒤)·얼굴·눈·눈썹·코·입·귀·목·옷·팔·다리·신발 등을 가려진 부분까지 복원해 RGBA 레이어로 나눕니다. (See-through 방법론 기반 자체 구현)

    3

    자동 리깅

    레이어마다 메시를 만들고 머리 회전·눈·시선·눈썹·입·몸·머리카락의 변형 키폼과 물리를 생성한 뒤 수치 QA로 접힘을 검사합니다.

    4

    바로 확인

    웹 뷰어에서 슬라이더·마우스·대기 모션으로 움직여 보고, 레이어·리그 보고서·파일을 모두 확인합니다.

    솔직한 한계

    • 자동 리그의 수준은 "기본 모션"입니다(깜빡임·시선·머리 회전·호흡·머리카락 흔들림). 전문가가 손으로 만든 Live2D 모델 수준은 아닙니다.
    • 감은 눈·벌린 입 그림은 생성하지 않습니다. 눈 감김은 속눈썹이 닫힘 곡선으로 내려오는 방식, 입 열림은 템플릿 입 모양으로 처리하며 결과 보고서에 degraded 로 표시됩니다. 모음(아이우에오) 입 모양은 아직 없습니다.
    • 전신 이미지는 얼굴이 작아 해상도가 부족할 수 있습니다. 얼굴 부위는 가능한 한 고해상도 결과를 사용하지만, 상반신·고해상도 입력이 더 좋은 결과를 줍니다.
    • 분해가 잘못될 수 있습니다(포니테일이 뒷머리에 합쳐짐, 안경·동물 귀 누락 등). 결과의 레이어 탭에서 실제 분해 결과를 그대로 확인할 수 있습니다.
    • 이 서비스는 Live2D Inc.와 무관하며 Cubism SDK를 사용하지 않습니다. 자체 형식으로 내보냅니다.
