## 1. 한 장 요약

**목표:** 사용자가 일러스트 1장 + prompt 를 올리면 → 브라우저에서 보고 움직일 수 있는 2D 퍼펫(Live2D 류)을 받는 웹 서비스.

**결론 3줄**
1. **된다 — 단 "Tier 1" 까지.** 눈 깜빡임·입 열림·호흡·머리카락 흔들림·작은 머리 회전·시선·idle. 프로급(Tier 3)은 아무도 못 했다. 제품 약속은 Tier 1, "할 수 없는 것을 정직하게 말하는 capability report" 를 붙인다.
2. **우리가 만들 것은 "리그 알고리즘"이 아니라 "소재 + 품질 보증 + 서비스"다.** 레이어 분해(See-through)와 리그 컴파일(psd2live 등)은 이미 OSS 가 있다. 비어 있는 곳은 ①**눈 감김·입 모양 변형 소재**(See-through 가 안 만들어 "입이 안 열리는데 에러도 없는" 조용한 실패가 남) ②**레이어 수리**(포니테일 병합·팔/몸통 병합·좌우 규약) ③**QA 루프**(수치 → 렌더 → VLM → 수리 → needs_review) ④**호스팅·무설치·리뷰 UI** ⑤**법적으로 깨끗한 경로** 이다. 아이디어 자체는 새롭지 않다(image2live2d 가 2026-07 에 같은 파이프라인을 공개) — **차별점은 품질·성공률·서비스·법무 청결성**.
3. **Live2D 파일(.moc3)은 "기술적으로 가능, 법적으로 회색"이라 MVP 에서 뺀다.** 자체 포맷(IRR, Cubism 동형 키폼) + 자체 WebGL 런타임으로 시작하고, `.moc3` 는 법무 게이트 뒤 옵트인 3단계. 사용자가 "자체 포맷도 OK" 라고 하셨으므로 이 순서가 가장 안전하다.

### Q2. Cubism 또는 상용 2D 툴 형식으로 만들 수 있나?
- **기술:** 가능하다. `.moc3` 쓰기를 구현한 OSS 가 이미 있다(psd2live GPL-3.0 530★ — 개발 머신에서 24레이어 PSD 로 9초에 `.moc3`(헤더 `MOC3` v5)를 생성했고 산출물이 남아 있음(V); image2live2d Apache-2.0; Umamo GPL-3.0). **단 Cubism Core/VTube Studio 에서의 로드는 아무도 독립 검증하지 않았고(제3자 README 주장뿐)**, 모두 "첫 초안" 수준이다.
- **법:** 병목은 `.moc3` 생성이 아니라 ①**Cubism Core 로 사용자 생성 모델을 웹에서 렌더링하면 "Expandable Application" — 소규모 면제 적용 불가, 사전 승인·별도 계약·수익 분배, "완전 무료는 원칙적 비승인"**(Core EULA 1.5/2.2 원문 직접 확인) ②**6.8 "2D 크리에이터의 창작성을 해칠 수 있는 용도" 금지**("일러스트 1장 → 자동 퍼핏"이 정면으로 걸릴 수 있음, 해석 U) ③디컴파일에 기댄 OSS 코드(StretchyStudio·py-moc3)의 출처 오염. Cubism Editor 는 서버 구동 불가(5.1.7 No Service Bureau).
- **결정:** **자체 포맷 + 자체 런타임 → (게이트) .moc3 내보내기**. 상세 `04`.

### Q3. 최신 공개 생성 모델(GPT 등)로 가능한가?
| 단계 | 답 |
|---|---|
| 레이어 분해 + 가림 인페인팅 | **애니 전용 공개 모델(See-through)이 이미 최선.** 범용 API 중 레이어 분해를 제품화한 곳은 Seedream 5.0 Pro 뿐인데 애니 시험 결과가 없다 |
| **눈·입 변형 생성** | **가장 잘 맞는 자리.** 편집 아레나 1위 `gpt-image-2.5-sunburst`(2026-09-08, 1522점), Nano Banana 2, FLUX 3 Image(어제 출시). 단 OpenAI 공식 가이드가 "픽셀 동일이 필요하면 원본에 합성하라" 권고 → **크롭·편집·합성 구조**. **애니 부위 변형을 따로 측정한 벤치마크는 공개된 게 없다** → 자체 평가 필수 |
| 머리 회전 | 새 시점 생성은 **측정 근거 없음**, 메시 워프로 처리. 생성 키프레임 정합은 공개 구현이 없어 R&D 트랙 |
| 비고 | **LLM(GPT-6 등)이 이미지를 직접 출력하지는 않는다**(도구 호출로 gpt-image-* 가 그림). **API 산출물로 우리 모델을 학습하면 약관 위반 소지**(OpenAI·Google·BFL·xAI·BytePlus). 업로드 애니 이미지는 API 필터 오탐·거부 가능성이 높아 **MVP 는 자체 호스팅(Qwen-Image-Edit-2511, Apache-2.0)을 기본, API 는 기준선·선택 어댑터** |

### Q4. 파이프라인 (완전한 구성)

```
 이미지 + prompt
   │ S0 검증·재인코딩·해시        (CPU, 샌드박스)
   │ S1 안전 게이트               (WD tagger v3 규칙 + 사람 큐 | 거절 시 GPU 비용 0)
   │ S2 계획                      (VLM: 전신/정면/애니, 얼굴·눈·입 박스, prompt → RigSpec[엄격 JSON])
   │ S3 분해                      (GPU: See-through V3 → 23층 + 깊이 + 순서)        ← 교체 가능 모듈
   │ S4 레이어 수리               (CPU: 좌우·앞/뒤 머리·원본 픽셀 재투영·오염 제거·언더랩)
   │ S5 변형 소재 합성            (GPU/API 어댑터: 눈 감김·입 모양, 크롭→편집→합성→검사→재시도)
   │ S6 사용자 리뷰 (선택)        (지우개/복원·분리선·앵커·RigSpec 수정·재굴림)
   │ S7 리그 컴파일               (결정론: 메시 → 디포머 → 파라미터/키폼 → 물리 → 모션 = IRR)
   │ S8 QA 루프                   (수치 불변식 → 렌더 시트 → VLM → 화이트리스트 수리 ≤3 → needs_review)
   └ S9 패키징 + 웹 뷰어          (슬라이더·웹캠·idle·립싱크 / 내보내기)
```
- **중심 계약 = IRR**(Cubism 동형 키폼 데이터). 컴파일러 4종(해석/psd2live 어댑터/학습 변위/생성 키프레임 정합), 런타임(자체 TS/WebGL2), QA, 내보내기(PSD·투명 영상·.inp·게이트 .moc3)가 모두 IRR 에 대해 교체 가능 (`03` §3).
- **LLM/VLM 은 계획·판정·스펙 작성만. 정점·키폼 수치는 절대 맡기지 않는다**(psd2live 자체 실측: "머리카락 분리·가림 보완은 불가").

### Q5. 웹 서비스
FastAPI + Postgres + Redis(RQ) + SSE + Next.js(자체 서버 compose) + **서버리스 GPU 워커 컨테이너**(Modal/RunPod) + SeaweedFS/R2. 퍼펫 1개당 **GPU ≈ $0.08–0.14**(150s 가정, U) / 변형 포함 시 **$0.2–0.8**(U). 무료 등급은 일일 쿼터 필수. 상세 `05`.

### M1 — 수직 슬라이스 (5–7주)
업로드 → 안전 게이트 → GPU 분해 → 레이어 뷰어 + **리뷰 UI** → C1 컴파일러 v0(얼굴·눈·입(변형 포함)·호흡·머리카락) → **IRR + 런타임 v0** → 뷰어(슬라이더·웹캠·idle) → 내보내기(PSD·불투명 영상·투명 PNG ZIP). 서비스 골격(상태기계·SSE·아티팩트·모니터링). **종료 기준:** 벤치 In-domain 에서 Tier 0 불변식 100%, 엔드투엔드 지연 측정, 런타임이 psd2live moc3 를 오픈 구현과 육안 정합.

### M2 — 품질·QA·prompt (5–7주)
변형 합성 + 자동 검사/재시도, **원본 픽셀 재투영**, 레이어 수리 규칙, **QA 루프(수치+VLM+수리)**, capability report, **prompt → RigSpec**, 모션 프리셋·립싱크, 부하 테스트, **비공개 베타**(초대제) + 모더레이션 운영. **종료 기준:** 베타 합격률이 M0 기준선 대비 개선, VLM–사람 상관 검증.

### M3 — 베타 확장 + Tier 2 파일럿 (6–8주)
계정·쿼터·(선택)결제, 보존·삭제·DMCA 운영, **Tier 2 파일럿**(생성 키프레임 정합 — `03` §4.4 C4), 레이어 재텍스처(prompt), `.inp`(nijilive) 내보내기. 학습형 컴파일러(C3)는 **합법 데이터 확보 시에만**.

### M4 — `.moc3` 내보내기 (+9–14주, **게이트 G0–G2 통과 시에만**)
"비공식/실험적, Live2D 와 무관" 표기, 기본 꺼짐, 낮은 moc3 버전(≤5)·5.3 기능 미사용, 자체 검증기 + 오픈 구현 로드 + 5개 이상 캐릭터 실기 QA(VTube Studio). G0 법무 허용 / G1 Live2D 서면 입장(또는 침묵) / G2 실기 QA. 하나라도 불통이면 M3 에서 멈춘다.

**대략 합계:** 비공개 베타까지 ≈ 4–5개월(U), `.moc3` 는 별도 +2–3개월.
